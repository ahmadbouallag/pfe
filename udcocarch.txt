UDoc: The Universal Document Engine
Architectural Specification v1.0
________________________________________
1. PHILOSOPHY & CORE THESIS
Thesis: Every document format, at its visual essence, is a container hierarchy — pages holding elements, slides holding shapes, sheets holding cells, flows holding blocks. The differences are not in the fundamental structure but in three dimensions:
Table 
Dimension	PDF	DOCX	HTML	XLSX	PPTX
Container type	Fixed page	Paginated flow	Infinite flow	Grid	Slide
Element geometry	Absolute	Mixed (flow + anchored)	Flow + positioned	Grid cell	Absolute
Reflow behavior	None	Full	Full	Structural	None
UDoc's mission is to unify at the container-element level while preserving each format's unique presentation semantics through adapter layers.
The Tab Principle: A UDoc document is a workspace containing multiple tabs. Each tab is an independent document view — pages, slides, spreadsheets, or infinite canvases. This mirrors how users actually work: one tab for the report, one for the appendix, one for the data tables. Other formats (DOCX, PDF) are single-tab subsets of this model.

3. THE UNIVERSAL CONTENT MODEL (LAYER 2)
3.1 Document
The root object. A document is a collection of tabs.
class Document {
    ID id;
    std::vector<std::unique_ptr<Tab>> tabs;
    std::unordered_map<ID, Tab*> tabMap;
    
    // Global metadata
    DocumentMetadata metadata;
    
    // Cross-tab links (internal navigation graph)
    LinkGraph internalLinks;
    
    // ID generation
    ID nextId = 1;
    
    // State (not serialized)
    ID activeTabId;
    bool modified = false;
};
3.2 Tab
A tab is a typed container that determines how its content is presented.
cpp 
Copy
enum class TabType {
    PageSequence,      // PDF, DOCX, ODF style
    SlideSequence,     // PPTX style
    GridSheet,         // XLSX style
    InfiniteCanvas,    // Whiteboard/drawing mode
    FlowDocument       // HTML/EPUB style (no pagination)
};

class Tab {
    ID id;
    QString name;
    TabType type;
    Color tabColor;           // UI hint
    
    // Content based on type
    std::variant<
        PageSequence,         // vector<Page>
        SlideSequence,        // vector<Slide>
        GridSheet,            // rows × cols grid
        InfiniteCanvas,       // bounding box + elements
        FlowDocument          // Story (blocks without page breaks)
    > content;
    
    // Tab-level properties
    PageLayout defaultLayout;  // For PageSequence tabs
    ZoomState zoomState;
    ViewState viewState;       // Scroll position, etc.
    
    // Tab can have its own header/footer (for page sequences)
    std::optional<HeaderFooter> masterHeaderFooter;
};
3.3 Page (Container)
The fundamental visual container. Pages exist in PageSequence and SlideSequence tabs. In FlowDocument tabs, pages are generated dynamically by the layout engine.
class Page {
    ID id;
    Tab* parent;
    
    // Geometry (always in points: 1/72 inch)
    double width, height;
    
    // Margins (content area = page - margins)
    double marginTop, marginBottom, marginLeft, marginRight;
    
    // Background
    Color backgroundColor;
    std::optional<ImageElement> backgroundImage;
    
    // Content: ordered by z-index (paint order)
    std::vector<std::unique_ptr<Element>> elements;
    
    // Master page reference (for inheritance)
    std::optional<ID> masterPageId;
    
    // Header/footer for this page (overrides tab default)
    std::optional<HeaderFooter> headerFooter;
    
    // Page-specific properties
    PageOrientation orientation;
    bool pageBreakBefore;
    
    // Spatial index (runtime, rebuilt on edit)
    mutable SpatialIndex spatialIndex;
    
    // Render cache (runtime)
    mutable PageCache cache;
};
3.4 Element (The Universal Atom)
Every piece of content is an Element. Elements are geometry-optional — they have position/size for fixed layouts (PDF, slides) but not for flow layouts (Word, HTML).
class Element : public UDocObject {
    ID id;
    Page* parent;             // nullptr for flow contexts
    
    // === GEOMETRY (optional, format-dependent) ===
    // For fixed layouts: absolute position on page
    // For flow layouts: computed during layout, not stored
    std::optional<Rect> bounds;
    std::optional<TransformMatrix> transform;
    
    // === Z-ORDER (for overlapping) ===
    int32_t zIndex = 0;
    
    // === VISUAL PROPERTIES ===
    double opacity = 1.0;
    std::optional<ClipPath> clipPath;
    bool visible = true;
    
    // === CONTENT (variant) ===
    std::variant<
        TextBlock,            // Flowing paragraph with inline runs
        Heading,              // Outline level, TOC entry
        List,                 // Bulleted/numbered with nested items
        Table,                // Grid of cells
        Image,                // Raster image
        VectorGraphic,        // SVG-like paths
        Media,                // Video/audio
        Formula,              // MathML/LaTeX
        Link,                 // Hyperlink or cross-reference
        Bookmark,             // Named anchor
        Field,                // Auto-updating field
        Comment,              // Annotation/comment
        Group                 // Nested elements
    > content;
    
    // === EDITING STATE (runtime, not serialized) ===
    bool selected = false;
    bool locked = false;
    bool editing = false;     // Text editing mode
    
    // === LINKS (this element as link source) ===
    std::optional<LinkTarget> linkTarget;
    
    // === ANCHORING (for flow documents) ===
    std::optional<AnchorProperties> anchor;  // inline, block, floating
    
    // Methods
    Rect transformedBounds() const;
    bool hitTest(const Point& p) const;
    bool isFlowElement() const;  // No stored geometry
    bool isFixedElement() const; // Has stored geometry
};
3.5 TextBlock (The Word Processor Element)
The most complex element. Supports full inline formatting.
struct TextBlock {
    // The text is stored as a flat string
    QString text;
    
    // Formatting is stored as runs (start, length, properties)
    std::vector<InlineRun> runs;
    
    // Paragraph-level properties
    ParagraphProperties paragraphProps;
    
    // Layout cache (runtime, invalidated on edit)
    mutable TextLayoutCache layoutCache;
};

struct InlineRun {
    uint32_t start;           // Index into TextBlock.text
    uint32_t length;
    
    CharacterProperties props;
    
    // Embedded objects within the run (images, fields, formulas)
    std::vector<EmbeddedObject> embedded;
};

struct ParagraphProperties {
    // Spacing
    double spaceBefore = 0;      // points
    double spaceAfter = 0;
    double lineSpacing = 1.15;   // multiplier
    double firstLineIndent = 0;
    double leftIndent = 0;
    double rightIndent = 0;
    
    // Alignment
    Alignment alignment = Alignment::Left;
    
    // Tabs
    std::vector<TabStop> tabStops;
    
    // Typography
    bool widowControl = true;
    bool orphanControl = true;
    bool keepWithNext = false;
    bool keepLinesTogether = false;
    bool pageBreakBefore = false;
    
    // Borders & shading
    std::optional<ParagraphBorder> border;
    std::optional<Shading> shading;
    
    // Numbering/list
    std::optional<ListProperties> listProps;
    
    // Style reference
    std::optional<QString> styleId;
};

3.8 Table (The Universal Grid)
Tables are recursive containers — each cell contains Elements.
struct Table {
    uint32_t rows, cols;
    
    // Dimensions (points)
    std::vector<double> rowHeights;   // Can be auto
    std::vector<double> colWidths;    // Can be auto or percentage
    
    // Cells
    std::vector<TableCell> cells;
    
    // Table-level properties
    TableProperties props;
};

struct TableCell {
    uint32_t row, col;
    uint32_t rowSpan = 1;
    uint32_t colSpan = 1;
    
    // Content: any elements
    std::vector<std::unique_ptr<Element>> content;
    
    // Cell properties
    CellProperties props;
};

struct TableProperties {
    double borderWidth = 0.5;
    Color borderColor{0, 0, 0, 1};
    
    // Header rows (repeat on new pages)
    uint32_t headerRows = 0;
    
    // Alignment
    TableHAlignment hAlign = TableHAlignment::Left;
    
    // Auto-fit behavior
    TableAutoFit autoFit = TableAutoFit::Auto;
};
3.9 Link (Internal & External)
struct Link {
    // Source: this element is the clickable region
    // Target: where it goes
    
    LinkTarget target;
    
    // Visual style
    Color color{0, 0, 1, 1};  // Blue default
    bool underline = true;
};

struct LinkTarget {
    enum class Type {
        ExternalURL,        // https://...
        DocumentInternal,   // Bookmark in this document
        CrossTab,           // Another tab in this document
        CrossPage,          // Specific page in this document
        CrossElement,       // Specific element in this document
        CrossDocument,      // Another UDoc file
        Email,              // mailto:
        File                // local file
    } type;
    
    // Target specification
    std::variant<
        QString,            // URL, email, file path
        ID,                 // Tab ID, Page ID, Element ID
        BookmarkReference   // Named anchor
    > target;
    
    // For cross-document links
    std::optional<QString> documentPath;
};

4.2 SlideSequence Tab (PPTX Style)
struct SlideSequence {
    std::vector<std::unique_ptr<Slide>> slides;
    
    // Slide master (background, placeholders)
    std::unique_ptr<SlideMaster> master;
    
    // Transition effects
    std::vector<SlideTransition> transitions;
};

struct Slide {
    ID id;
    double width, height;     // Usually 10" × 7.5" (standard) or 16:9
    
    // Background (solid, gradient, image)

    // Elements (absolute positioning, like PDF)
    std::vector<std::unique_ptr<Element>> elements;
    
    // Slide layout template reference

    std::vector<AnimationStep> animations;
    
    // Notes (speaker notes)
    std::optional<TextBlock> notes;
};
4.3 GridSheet Tab (XLSX Style)
struct GridSheet {
    // Infinite grid (sparse storage)
    std::unordered_map<uint64_t, std::unique_ptr<Cell>> cells;
    
    // Column/row metadata
    std::unordered_map<uint32_t, ColumnProperties> columns;
    std::unordered_map<uint32_t, RowProperties> rows;
    
    // Named ranges
    std::unordered_map<QString, CellRange> namedRanges;
    
    // Formulas (dependency graph)
    FormulaEngine formulaEngine;
    
    // View properties
    GridViewState viewState;
};

struct Cell {
    uint32_t row, col;
    
    // Content
    std::variant<
        double,           // Number
        QString,          // Text
        bool,             // Boolean
        QDateTime,        // Date
        FormulaCell,      // Formula
        ErrorValue        // #REF!, #DIV/0!, etc.
    > value;
    
    // Formatting
    CellFormat format;
    
    // Merged cell reference
    std::optional<uint64_t> mergeParent;  // Hash of top-left cell
    
    // Comments
    std::vector<Comment> comments;
};

// Hash function for cell coordinates
inline uint64_t cellHash(uint32_t row, uint32_t col) {
    return (static_cast<uint64_t>(row) << 32) | col;
}
4.4 InfiniteCanvas Tab
struct InfiniteCanvas {
    // No fixed size — expands as elements are added
    Rect contentBounds;  // Computed from elements
    
    // Zoom/pan state
    double zoom = 1.0;
    Point scrollOffset;
    
    // Elements (absolute positioning, infinite bounds)
    std::vector<std::unique_ptr<Element>> elements;
    
    // Grid/snapping
    bool showGrid = true;
    double gridSize = 20.0;
    bool snapToGrid = false;
};

struct FlowDocument {

5. THE LINK SYSTEM (Cross-Reference Architecture)
Links are first-class citizens in UDoc. Every element can be a link source, and every identifiable location can be a link target.
class LinkGraph {
    // Bidirectional link index
    std::unordered_map<ID, std::vector<LinkEdge>> outgoing;  // element → targets
    std::unordered_map<ID, std::vector<LinkEdge>> incoming;  // target → sources
    
public:
    void addLink(ID sourceElement, const LinkTarget& target);
    void removeLink(ID sourceElement);
    void updateTarget(ID sourceElement, const LinkTarget& newTarget);
    
    // Query
    std::vector<LinkEdge> getLinksFrom(ID element);
    std::vector<LinkEdge> getLinksTo(ID target);
    
    // Validation: find broken links
    std::vector<BrokenLink> validate();
    
    // Navigation
    bool followLink(ID sourceElement, DocumentViewport* viewport);
};

// === BASE INTERFACE ===
class FormatParser {
public:
    virtual ~FormatParser() = default;
    
    // Parse file → UDoc Document
    virtual std::unique_ptr<Document> parse(const std::string& path) = 0;
    
    // Quick format detection (magic bytes, extension)
    virtual bool canParse(const std::string& path) = 0;
    
    // Metadata extraction
    virtual DocumentMetadata extractMetadata(const std::string& path) = 0;
    
    // Element extraction (your "advanced extraction" requirement)
    virtual std::vector<ElementReference> extractElements(
        const std::string& path,
        const ExtractionFilter& filter
    ) = 0;
    
    // Streaming parse (for large files)
    virtual void parseStreaming(
        const std::string& path,
        std::function<void(std::unique_ptr<Page>)> pageCallback,
        std::function<void(std::unique_ptr<Element>)> elementCallback
    ) = 0;
};

// === EXTRACTION FILTER SYSTEM ===

    std::optional<std::set<ElementType>> types;

    // Size filter
    std::optional<double> minWidth, maxWidth;
    std::optional<double> minHeight, maxHeight;

};
